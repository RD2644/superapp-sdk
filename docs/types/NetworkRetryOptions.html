    Type Alias NetworkRetryOptions

    Retry policy for NetworkModule.send.

    Remarks

    A response is retried when its status_code is a server error (5xx) other than 501, or when the JSBridge call throws. 501 (not running in the Grab app) and client errors (4xx) are never retried. Delays grow exponentially: baseDelayMs * 2^(attempt - 1), capped at maxDelayMs.

    OptionalbaseDelayMs

    baseDelayMs?: number

    Delay before the first retry, in milliseconds. Defaults to 200.

    Optionaljitter

    jitter?: boolean

    Whether to randomize each delay between 0 and the computed value ("full jitter"). Defaults to true.

    OptionalmaxAttempts

    maxAttempts?: number

    Maximum number of attempts, including the first one. Set to 1 to disable retries. Defaults to 3.

    OptionalmaxDelayMs

    maxDelayMs?: number

    Upper bound for any single delay, in milliseconds. Defaults to 2000.

    OptionalretryableMethods

    retryableMethods?: SendMethod[]

    HTTP methods that may be retried. Defaults to the idempotent methods GET, HEAD, OPTIONS, PUT and DELETE. Only add POST or PATCH when the endpoint is idempotent (for example, it deduplicates on an idempotency key).
